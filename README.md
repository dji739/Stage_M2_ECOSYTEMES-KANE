# Stage_M2_ECOSYTEMES-KANE

Ce répertoire contient le fichier .Rmd utilisé lors de mon stage de M2, pour mener à bien l'analyse bibliométrique d'un corpus issu des 130 principaux journaux de la conservation. Les fichiers utilisés sont disponibles sur demande, et les chemins d'accès seront à adapter en fonction de la configuration du poste utilisé.
L'ensemble des fichiers répertoriés sont sous license Creative Commons, CC-0 (Universal).
