# Stage_M2_ECOSYTEMES-KANE

Ce répertoire contient :
- le fichier .Rmd utilisé lors de mon stage de M2, pour mener à bien l'analyse bibliométrique d'un corpus issu des 130 principaux journaux de la conservation. Les fichiers utilisés sont disponibles sur demande, et les chemins d'accès seront à adapter en fonction de la configuration du poste utilisé. Nom du fichier : Analyse_bibliometrique.Rmd7
- deux fichiers décrivant les corpus utilisés lors de l'étude : Corpus Principal (CP) et Corpus Associé (CA)
